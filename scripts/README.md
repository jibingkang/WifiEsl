# WifiEsl Manager Scripts

All deployment and management scripts for the WifiEsl electronic shelf label management system.

---

## Quick Start

| Scenario | Command |
|----------|---------|
| First time setup | `deploy.bat` |
| Dev mode (hot reload) | `start_dev.bat` |
| Production run | `start.bat` |
| Stop all services | `stop.bat` |
| Install as Windows service | `install_service.bat` (Run as Admin) |
| Uninstall service | `uninstall_service.bat` (Run as Admin) |
| Build distributable package | `build_package.bat` |

---

## Script Details

### `deploy.bat`
One-click environment setup.
- Detects Python 3 automatically
- Creates virtual environment
- Installs all Python dependencies
- Builds frontend production bundle
- Run once on a new machine or after pulling updates

### `start.bat`
Production mode - single process serves both API and frontend.
- Auto-creates venv and installs deps if needed
- Opens `http://localhost:8001`
- Default login: `admin` / `admin123`

### `start_dev.bat`
Development mode - two windows with hot reload.
- Backend on `http://localhost:8001`
- Frontend on `http://localhost:3000`
- Code changes auto-refresh

### `stop.bat`
Kills all WifiEsl processes by window title and port (8001, 3000).

### `install_service.bat`
Registers as Windows service (auto-start on boot).
- **Requires Administrator privileges**
- Service name: `WifiEslServer`
- Auto-restarts on crash

### `uninstall_service.bat`
Removes the Windows service.
- **Requires Administrator privileges**

### `build_package.bat`
Packages the project into `build/` directory for distribution.
- Copies backend + frontend dist
- Generates `docker-compose.yml` and `nginx.conf`
- Includes embedded `start.bat` for deployment machines

## Environment Config (.env)

Edit the `.env` file in the project root with your WIFI tag system credentials:

```ini
WIFI_BASE_URL=http://192.168.1.172:4000
WIFI_USERNAME=your_username
WIFI_PASSWORD=your_password
WIFI_APIKEY=your_api_key
MQTT_BROKER_HOST=192.168.1.172
MQTT_BROKER_PORT=8883
BACKEND_PORT=8001
JWT_SECRET=your-secret-key
```
